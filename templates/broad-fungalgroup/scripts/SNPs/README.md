# Legacy Broad-derived SNP utilities

`vcfSnpsToFasta.py` is retained for historical provenance and regression comparison.
It is no longer invoked by the FungiPhyloGen production workflow as of version 1.2.0.

Production SNP alignment construction is implemented in:

`scripts/fpg_vcf_to_snp_alignment.py`

Do not use the legacy converter for new FungiPhyloGen analyses.
